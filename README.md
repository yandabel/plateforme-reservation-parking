# 🚗 Plateforme de Réservation de Parking

Une application web permettant aux utilisateurs de réserver des places de parking en ligne.

---

## 🛠️ Technologies utilisées

### Frontend
- ReactJS
- Axios
- React Router

### Backend
- NodeJS
- ExpressJS

### Base de données
- MongoDB
- Mongoose

---

## ⚙️ Installation du projet

###  Cloner le projet

```bash
git clone https://github.com/yandabel/plateforme-reservation-parking.git
cd plateforme-reservation-parking

### Instalation Backend
cd backend
npm install
npm run dev

### Installation Frontend
cd frontend
npm install
npm start
